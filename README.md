# Linux CLI Monitoring Guardian 🛡️

Легковесная и мощная CLI-утилита на языке **Go (Golang)** для мониторинга состояния операционной системы Linux в реальном времени. Интегрирована с базой данных **PostgreSQL** для надёжного и структурированного логирования системных сбоев.

## 🚀 Ключевые возможности

- **Пульс системы (`Life`):** Мониторинг времени аптайма ОС и точный расчёт оперативной памяти (Свободно/Всего/Занято в ГБ) путём парсинга системных файлов ядра (`/proc/uptime`, `/proc/meminfo`).
- **Информация о процессоре (`HW`):** Сбор метрик CPU, определение модели процессора и подсчёт общего количества доступных ядер и потоков из `/proc/cpuinfo`.
- **Автоматический сетевой радар (`NetworkR`):** Сканирование задержки сети через ICMP-пинг. Автоматически перехватывает полные обрывы связи или критические скачки пинга (>300 мс) и мгновенно записывает аварию в базу данных.
- **Работа с PostgreSQL (`ConnBD`, `ShowL`, `Clean`):** 
  - Автоматическое развёртывание структуры таблиц прямо при старте утилиты.
  - Построчный парсинг, очистка от системных символов и форматирование дат через строковые срезы Go для красивого вывода истории логов (`SELECT`).
  - Быстрая и безопасная очистка таблицы логов одной командой (`TRUNCATE`).
- **Менеджер процессов (`TP`):** Вывод ТОП-15 процессов, наиболее нагружающих оперативную память, со встроенным инструментом завершения любого процесса по его `PID` (`kill <PID>`).
- **Анализ накопителей (`InfoD`):** Проверка свободного места на всех смонтированных дисках системы.
- **Глобальная интеграция в ОС:** Компилируется в независимый бинарный файл и разворачивается глобально в `/usr/local/bin` для вызова по одной короткой команде.

## 🛠️ Стек технологий

- **Язык программирования:** Go (Golang)
- **База данных:** PostgreSQL (использование стандартного пакета `database/sql` и драйвера `://github.com`)
- **Операционная система:** Linux (дистрибутив **Fedora**)
- **Система контроля версий:** Git

## 📦 Инструкция по развёртыванию и запуску

### Предварительные требования
Убедитесь, что на вашем компьютере установлен и запущен PostgreSQL:
```bash
sudo dnf update && sudo dnf install postgresql-server postgresql-contrib -y
sudo postgresql-setup --initdb  
sudo systemctl start postgresql
```

### 1. Настройка базы данных
Зайдите в терминал управления PostgreSQL и выполните команды для создания пользователя и базы данных:
```sql
sudo -u postgres psql

-- Внутри терминала СУБД:
CREATE USER ivory_user WITH PASSWORD 'secure_ivory_pass';
CREATE DATABASE ivbase OWNER ivory_user;
GRANT ALL PRIVILEGES ON DATABASE ivbase TO ivory_user;
\q
```

### 2. Компиляция и установка утилиты
Клонируйте репозиторий, инициализируйте модули, соберите проект в бинарник и перенесите его в системную директорию Linux:
```bash
# Инициализация модулей Go
go mod init linux-cli-monitoring-guardian
go mod tidy

# Сборка всех файлов проекта в один исполняемый файл
go build -o ivory .

# Выдача прав на запуск и установка в систему
chmod +x ivory
sudo cp ivory /usr/local/bin/
```

### 3. Запуск программы
Теперь вы можете открыть абсолютно любое окно терминала и запустить утилиту из любой папки всего одним словом:
```bash
ivory
```
